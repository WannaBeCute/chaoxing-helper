说明

AI 对话会把题目文本、你发送的文档文本和对话内容发送给所配置的 API 服务商。请确认你接受对应服务商的隐私政策。

超星页面上的填入、图片/附件上传仍由扩展调用页面自身接口完成；AI 回复不会自动写入作业，需要你在对话里点击“填入当前光标”。
